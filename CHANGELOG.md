# Changelog · 更新记录

## v0.7.0 — 2026-10-07

### 中文

- 默认采用克制的细经纬画布，先保原曝光、光向与主色，再按题材取舍细节和选择局部效果；修正入口仍将暗底作为前提的旧说明。
- 汇入作品逐图研究、七组参考选择与主题适配方法；增加当前验收记录，明确秋叶中间稿、礁岸最终稿及其他用户选定版本，保留失败与撤回记录。
- README 改为中英双语，更新技能元数据与历史测试入口。公开包继续排除用户作品、真实测试原片与新测试结果，也排除未认可的历史 AI 调色资源。
- 通过记录仅对应具体输入；复杂公园仍未通过。公开参考条件与私有参考库的出图效果尚未验证等价。

### English

- Prioritize restrained fine canvas, source exposure, lighting, and color before subject-specific simplification and local effects. Remove the outdated dark-background prerequisite from the skill interface.
- Include per-work observations, seven reference groups, adaptation guidance, and a current acceptance record. Preserve rejected and withdrawn versions alongside the user's selected outputs.
- Provide a bilingual README and update metadata and historical-document routing. Packages exclude private works, real test photographs, new test outputs, and unapproved historical AI calibration assets.
- Acceptance applies to specific inputs. Complex park scenes remain unapproved, and public-only reference conditions have not been demonstrated equivalent to the private library.
