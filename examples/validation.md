| 检查 | 结果 | 观察 |
| --- | --- | --- |
| 目标场景 | PASS | 天空为主体，下沿树线，上右枝叶，左侧一只小鸟；没有照搬参考构图 |
| 中性烟灰色域 | PASS | 没有旧金光束或大面积暖褐色；黑白灰为主 |
| 暗部与云层 | PASS | 树叶较黑，云层有浅灰到炭灰梯度 |
| 细平表面 | PASS，有偏差 | 比初次生成的亚麻更细、更平；目视仍比部分参考稍明显 |
| 非整图模糊 | PASS | 枝叶轮廓可辨，云团与远景柔软 |
| 具体枝叶稀疏度 | 偏差 | 上右枝叶比提示词中的 sparse 更密 |

## 默认中性灰：已有图像转换

原图：[AI 合成普通照片式输入](transfer-source.png)。结果：[中性灰转换](transfer-neutral.png)。此输入不是真实拍摄照片；没有真实人像、文字或精密几何保真测试。

| 检查 | 结果 | 观察 |
| --- | --- | --- |
| 基本画面结构 | PASS，限目视大结构 | 左侧树、右侧船屋、斜栈桥、单条小船、岸边石块与远山均保留；非逐像素对齐 |
| 画幅 | PASS | 输入输出均 1536 × 1024，3:2 |
| 新增鸟/风筝/对象 | PASS | 未见新增鸟、风筝或额外船只 |
| 有限中性灰与暗部 | PASS | 彩色转为轻暖烟灰，树叶和栈桥暗部显著收暗，房屋保持较浅 |
| 细平纹理 | PASS，有偏差 | 连续细纹出现；木纹与表面效果略较刻画 |

## Creative OS 暖灰变体

- [暖灰从零生成](generate-cloud-bird.png)：有限灰褐色域、织纹、阴云、植物与一个飞鸟均出现。但提示词要求的湖岸、水面不明确，结果更像仰拍树冠；织纹和色温也比用户新发的摄影参考更重。
- [暖灰转换](transfer-dark-canvas.png)：基本船屋/栈桥/一条小船结构保留，连续织纹与灰褐色出现。但天空被较大幅重绘，并出现较戏剧化的暖色亮区，未通过严格的场景光照保持要求。

这两个输出保留作对照，不用来证明默认中性灰风格已经达成。
