# v0.5.0 · 原色保持、毛笔笔意与真实织纹

2026-10-03，用户指出上一轮偏水彩、调色过大、微细节过分显露，纸/表面材质不对。本轮默认改为保持源图主色关系，用中国毛笔般概括形成统一色面，以真实亚麻素材校准经纬结构。山水画用于笔意与意境，不能自动换成山水母题。上一轮 [记录](validation-v0.4.1.md) 与 [对照](../preview-v0.4.1.html) 保留，但不作为当前风格已通过的依据。

## 实际执行与选图

本轮 Codex 内建 image_gen 共 **4 次实际出图**：真实湖面 1 版、AI 静物 3 版；每版实际查看，原始输出只复制保存，未加滤镜、锐化、裁切或纹理后期。完整实际 [提示词](brush-linen/prompts.md) 与 [尺寸/校验清单](brush-linen/manifest.json) 可检查。输入分为原图（主题/颜色/裁切）、用户作品参考（仅笔意/背景关系）、真实灰度亚麻素材（仅纤维结构）。这次只重测自然和静物，未重测其他主题；此前城市/人物记录只提供历史经验，不能证明新版本已覆盖所有主题或跨模型。

| 版本 | 实际观察 | 判断与选择 |
| --- | --- | --- |
| 湖面 v1，1448×1086 | 原有柳幕、岸树、湖水、微小暖灯/青灯及 4:3 安排保留；细经纬比上一轮卷曲纹路更规整。没有改成冷蓝，但天空/湖水仍比源图亮、偏褐；枝叶与倒影仍细 | 本地保存唯一候选；色彩和毛笔概括仍有偏差，**部分达成** |

## 六项检查（所选候选）

| 条件 | 湖面 v1 | 静物 v3 |
| --- | --- | --- |
| 色彩保持 | 有偏差：偏亮偏褐，不能称完全保色 | 主色系保留；有偏差：暗亮比例/局部饱和度改变 |
| 整体安静统一 | 背景较统一；叶与倒影仍细 | 改善明显：高光/塑形收起；局部纹理仍繁 |
| 实物织纹/概括 | 经纬改善，不能因此判整图通过 | 经纬可见并融入主体；局部卷曲痕迹仍有偏差 |
| 主题与明确条件 | 通过：柳幕、湖水、灯、原画幅仍在 | 通过：一杯一把手、一碟一勺、方形安排仍在 |
| 毛笔笔意与诗意 | 只部分达成，不能凭题材判山水笔意通过 | 简洁色形与干笔边缘改善；不能称完全达到参考笔意 |
| 文件/成品完整性 | 已取得并看图，未见新增文字/角落标识 | 已取得并看图，未见新增文字/角落标识 |

静物已用完默认两次修正，保存各版并选择最接近目标的一版；不继续无限生成，不把“有素材”或工具调用成功记为视觉通过。两个主题均保留残余偏差，用户最终审美认可另行记录。

公开新静物 AI 输出、提示词、记录及有许可的材质。真实湖面源图、湖面结果与用户摄影作品仅本地保存于 `local-reference/tests/2026-10-03-brush-linen/`，提供原图/各版/参考/材质对照。原文件与另一 AI 的工作树未改动。

## 验证范围

PNG 签名、尺寸与块校验已通过；生成输出复制后的 SHA256 与工具原文件一致。素材字节数及 SHA256 与下载记录一致。机械检查只验证文件与发布包；无法代替毛笔笔意、原色保持与诗意的目视判断。其他模型、独立 agent 行为、真实人物身份、精确文字未验证。本轮浏览器切换仅作脚本语法检查，不宣称点击实测。
