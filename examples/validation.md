# v0.4.0 当前实测与复核

2026-10-03，Codex 内建 image_gen；共 **9 次实际出图**：4 张初稿、4 次第一次修正、静物另一次修正。全部输出实际查看，原始 PNG 保留。完整提示词见 [调用记录](adaptive/prompts.md)，尺寸与选版见 [清单](adaptive/manifest.json)。这是作者按 skill 手动执行的样本测试，**没有独立 agent 或跨模型评测**。

用户补充“最后的成果是有诗意的风格”。因此初稿的内容正确不等于最终通过：细平纹、暗色与低饱和也不自动构成诗意。修正围绕每个主题的光、层次、空间与情绪关系进行。

## 选版与边界

最终保留街道 v2、静物 v3、人物 v2、湖面 v2；不是无条件选择末版。静物 v2 内容正确但意境不足，经过第二次修正才选 v3。原图转换从原始照片重新附入，避免连续编辑漂移；新静物测试未规定原始取景，允许重新构图。真实照片若未授权重构，不能照搬这种调整。

本地完整对照保存于项目 `local-reference/tests/2026-10-03/preview.html`，包含初稿、每轮修正和湖面原图；公开 `preview.html` 只展示新生成的三个主题与历史样本入口。

## 对 v0.3 历史记录的复核

- [原记录](validation-history.md) 保留追溯，不沿用其笼统 PASS。冷蓝船模板要求两人，历史图实际为三人；数量未通过。
- 单色月枝历史样本有旋涡笔触、边缘框感与轻微色偏，不能证明精确匹配竖幅清晰枝月参考。
- 暖金样本构图与参考高度接近，不能用来证明独立新场景的适配能力。
- 历史 WorkBuddy 样本有「AI生成」标识；本轮九张 Codex 输出目视没有对应角落字样。宿主行为必须分别记录，不推断为所有 image_gen 的通性。未做水印擦除。
- 亚麻油画、低地平线、天空占 2/3、3:2 与至多一个锐利锚点不再设为所有主题的恒定规则。

## 验证范围

发布前实测：官方 quick_validate 对项目技能与解压安装包均通过；9 张 PNG 的头部、尺寸与全部块 CRC 校验通过；项目、完整本地 HTML 与独立安装包的链接目标检查通过，项目/本地页共 83 处、0 断链；ZIP testzip 通过，未含摄影参考或用户原图。HTML 切换脚本完成语法检查，但本轮没有可用浏览器进行实际点击测试。机械检查不证明视觉效果。未覆盖精确文字、真实人脸身份、所有主题、其他风格体系与其他生成模型。当前样本显示跨主题生成及针对失败修正实际执行过，不能承诺任意输入必然成功。
