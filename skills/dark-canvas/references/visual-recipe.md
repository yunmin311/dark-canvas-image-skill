# 视觉配方

配方来自对用户提供的二十四张参考图的逐张目视分析，外加两张已认可的 Creative OS 生成案例。**不是摄影师的技术自述。** 第三方参考图仅存于本地忽略目录，不随仓库分发。

## 关键校准结论（2026-10-02 实测）

上一版配方把默认设为「中性烟灰近黑白」，并在多处要求「不是油画 / 去掉笔触 / never an oil painting」。逐张复核二十四张参考后，这个判断是错的，已废除：

| 上一版判断 | 复核后的事实 | 证据 |
| --- | --- | --- |
| 默认中性烟灰近黑白 | **暖金／赭石／麦色是压倒性主调**，二十四张里约十五张以暖金天空或暖金水面为主 | 鸟枝金天空、橙色云群飞鸟、金光湖面群山、夕照橙湖、暖金柳枝月、橙金树冠、金色天空群鸟、暖金竹叶雀 |
| 「不是油画」「去掉笔触」 | 参考明显是**亚麻布面油画**：柔和晕开的色团、羽化边缘、以明度塑形、可见经纬织纹 | 全部二十四张；用户本人也形容为「油画的诗意感」 |
| 表面要「极细、只有放大才可见」 | 织纹在**缩略图级别就明显可见**，且是识别该风格的主要线索 | 橙云飞鸟、夕照橙湖、暖金树冠、橙金树与漏光 |
| 默认主体稀少、「不要把案例里的小鸟自动加入」 | 鸟／飞鸟是**高频核心母题**，出现在至少八张里 | 鸟枝、鸟群、鹤归月、雀竹、双飞鸟、飞鸟云、金空群鸟 |

保留旧版判断的部分：低地平线、大面积留白、近黑剪影、单一暖色小锚点、边缘旧印相痕迹。

## 表面：亚麻布面油画（默认）

这是本风格最先被识别、也最容易做错的特征。

- **可见经纬织纹**：细亚麻经纬线在天空、水面、剪影上**连续贯通**，缩略图级别即可见。不可做成只在放大后出现的微噪。
- **哑光**：无高光反射、无清漆感、无数码照片的锐利。
- **以明度塑形**：形体靠明暗团块交代，不靠轮廓线；边缘羽化、柔和。
- **不是**：厚涂立体堆叠（impasto）、粗麻袋、规则数字网格、浮雕滤镜。

## 构图解剖

二十四张共有的骨架，缺一条就会立刻脱离该family：

1. **3:2 横幅**，地平线压低。
2. **天空／水面占约三分之二**，大面积留白。
3. **层次退远的山**：一道比一道更淡、更低对比，形成空气透视。
4. **近黑剪影**从底部或下角进入，作为天然画框；暗部内部要有层次，不能压成一块死黑。
5. **至多一个清晰锐利的视觉锚点**（一只鸟、一轮月、一叶帆），其余全部柔和。
6. **不对称、克制**，不居中、不对角平衡、不做英雄式构图。

## 色域

默认暖金是主线，其余色域按需选择，**不要一次全堆上**：

| 色域 | 用在 |
| --- | --- |
| 暖金／赭石／麦色（默认） | 金色天空、橙色云、夕照湖面 |
| 烟灰近黑白 | 单色变体（月、枯枝、阴云） |
| 灰橄榄／煤黑 | 雾中群山、雨后远景 |
| 旧金／褐黑 | 边缘漏光 |
| 少量氧化红 | 船、屋顶等**唯一**的暖色锚点 |

**冷色是例外，不是主线**：二十四张里只有两三张偏蓝或青灰。默认禁止鲜蓝、青色、橙青电影调色、HDR 浓淡。

### 参考用色（目视取样，供对色参考）

暖金天空 `#C89B4A`｜烟灰云 `#77766B`｜灰橄榄远山 `#696A4D`｜炭黑剪影 `#20211B`｜旧金漏光 `#A18C4F`｜羊皮纸白 `#C8B99A`

调色以观感为准，不假装工具能执行十六进制精确上色；更不要为了用齐色卡而制造彩色物体。

## 母题词汇

这些是这个摄影师反复拍的东西，**属于风格的一部分**，不是"从案例里自动加入"：

- **鸟**：单只停枝、群飞、归鸟掠过月、雀栖竹——最高频母题
- **柳枝／枝叶自上方垂入**，形成画框
- **水面与远山**，带小船／竹筏
- **月或日**作为小而亮的圆盘
- **枯枝逆光**
- **田野／农人／船屋**等朴素人造物，作微小尺度参照

## 变体选择

| 变体 | 色调与明暗 | 母题倾向 | 表面 |
| --- | --- | --- | --- |
| 暖金亚麻（默认） | 金色天空、烟灰云、灰橄榄远山、近黑剪影 | 群鸟、柳枝、水面远山 | 可见亚麻织纹 |
| 烟灰单色 | 纯黑白，无色偏 | 月、枯枝、阴云 | 织纹最明显 |
| 灰橄榄雾 | 灰橄榄、煤黑、少量暖灰 | 雾中群山、拖影枝叶 | 织纹 + 轻方向性拖影 |
| 旧金漏光 | 低饱和土黄、褐黑 | 树影，**仅一侧边缘**漏光 | 织纹 + 单边暖色漏光 |
| 蓝调偶发 | 冷蓝灰（参考中少数） | 船、月 | 织纹 |

**只用一个变体。** 漏光、拖影、颗粒按需，不是每张必加；不要全图高斯模糊。

## 照片转换的优先级

先保结构与身份，再匹配色域／明暗，最后加表面与局部软化。主体与参考不同并不要求换成树林——**保留原图内容**，人脸保留辨识，室内保留家具透视，城市保留建筑道路。转换是把照片重画成这种油画，不是把照片套一层滤镜。

## 常见偏差与定向修正

| 偏差 | 下一次只修什么 |
| --- | --- |
| 变成棕调复古滤镜 | 回到暖金主调，加金／琥珀天空，压低饱和 |
| 织纹太细看不见 | **放大织纹尺度到缩略图可见**，不要改色域 |
| 织纹太粗像麻袋 | 缩小经纬线尺度、压平，去掉立体感 |
| 数码照片感／锐利 | 加强晕开色团与羽化边缘，去高光反射 |
| 主体太满、构图挤 | 扩大留白到三分之二天空，缩小主体 |
| 缺母题、像空风景 | 按母题词汇加一处鸟／柳枝／小船，别都加 |
| 太亮太艳 | 压暗中间调、收窄色域，保留天空开口亮度 |
| 一片黑 | 恢复天空层次与暗部内部细节 |
| 转换后新增／丢失对象 | 回到原图，逐项重申要保留的对象与位置 |
