# 平静布面的诗意配方

当前依据：用户 2026-10-03 明确纠正，最终要平、静、像在油画布上画出的诗意，中国山水画般含蓄；不追求写实清晰、强空间或鲜明层次。这个目标优先于历史版本的解释。用户提供的二十四张照片有多种色调与清晰度，作者由用户指认为 Pablo Bueno，实际制作工艺与小红书身份未独立核实。

## 整体画面

- **平**：减弱透视与光影带来的强烈纵深，将前后景视为同一布面上相互融入的色形。保留主要摆放关系，不用改物件位置去压平空间。远近仍可存在，无需主动增强它。
- **静**：压住刺眼光点、镜面高光、坚硬明暗切割与密集细节竞争；大色面平缓融合，留有停顿。色彩可冷、可暖、可局部偏鲜明，没有固定褐色滤镜。
- **画在布上**：细腻连续的经纬纹贯穿画面，薄颜料渗入或轻覆纹理，哑光、柔软、轻微不均匀；主体也参与这种融合，避免高清照片与独立纹理叠层的两张皮。
- **概括**：叶片、砖石、木纹、毛孔、金属反光可成为少量色形与笔意，边缘可若隐若现。允许细节消失；不要一见柔化就锐化补回去。也不要把整张图做成无差别高斯模糊。

中国山水画的类比用于整体含蓄与平静观看，不是每张都要水墨纸、远山、亭子或书法。油画画布的类比用于表面与薄颜料，不等于浓重古典油画、厚涂雕塑或旋涡笔触。本文不推断摄影师真的使用这些材料。

## 按主题概括

| 主题 | 适配方式 | 保留到什么程度 |
| --- | --- | --- |
| 自然/湖面 | 岸树与倒影成为安静色形，枝叶可部分消隐，天水色面融合 | 主要岸线、枝幕与画幅；不要求逐叶和精确云形 |
| 城市/建筑 | 墙、路与天空合为低对比色面，门窗/砖缝仅少量痕迹，湿地光泽变哑 | 基本街道与建筑安排、指定人物/物件数量；无需增强消失点 |
| 人物/动物 | 神态与姿态用克制笔意呈现，衣料/肤质概括，轮廓可融入环境 | 用户要的主体与姿态；真实身份如明确要求须单独核验，不能以锐化替代身份保持 |
| 静物/产品 | 杯、碟、材料用柔和色块呈现，高光与投影融进布面，弱化体积塑造 | 指定物件与基本形状/数量；精准商标和产品细节只在明确要求时保留 |
| 多主体场景 | 用色面归并繁碎细节，让整体一致平静，不强行只留一个主体 | 用户指定的内容与大安排；柔化不是删主体的许可 |

适配的是主题与色彩，布面统一、安静概括是本项目当前默认意境。用户明确提出其他视觉体系时服从新目标，不能强加织纹。

## 选参考

选最接近本次色彩与概括程度的 1–3 张实际看图，并明确借用部分：比如一张借冷蓝色面，一张借连续画布表面；不借其船、人或枝条排列。没有参考时可用技能内已认可的 Creative OS 案例作布面关系依据，不能认定所有历史样本都正确。

参考较清楚的局部不要求全图照样清楚；最新用户目标决定整体概括程度。保持当前需求的颜色，不把暖灰表面参考的暖色强加给冷蓝画面。

## 有偏差时如何修

| 实际问题 | 修正方向 |
| --- | --- |
| 仍像高清照片套纹理 | 概括主体自身的细节与材质，压微反差/光泽，融合边缘与色面，再检查主体是否像薄颜料画出 |
| 空间强、明暗层次太分明 | 压缩色调差异，减弱前后景对比和聚光效果；保留原几何，不挪物件 |
| 只变糊，布面和笔意没出现 | 用薄颜料的形状概括与连续细织纹重绘，不再追加全局虚焦 |
| 像厚涂或粗麻袋 | 压平颜料与表面对比，减小纤维尺度，让织纹安静贯穿 |
| 色彩被参考带偏 | 保留目标色彩关系，只借参考的融合、概括与布面 |
| 指定主体或数量丢失 | 从原图或最佳版本恢复所需基本形状，不连带恢复全部写实细节 |
| 精确文字/身份要求未满足 | 单独记录失败并针对它修正；不能把身份偏差解释成绘画概括 |

构图位置、叶形或鸟群排列与参考高度重合时应记为参考重绘，不能称为独立新构图。实际图是否符合当前意境需要看图判断，用户审美认可不由作者自检代替。
