# 主题与视觉处理

依据用户提供的二十四个参考文件、之前的六格拼图和两张 Creative OS 生成案例观察。作品作者由用户指认为 Pablo Bueno；小红书账号未独立核实，实际制作工艺未知。本文描述画面，不声称摄影师使用了油画或特定后期技术。

## 将不同因素分别决定

| 因素 | 可用范围 | 选择依据 |
| --- | --- | --- |
| 色彩 | 中性烟灰、轻暖灰、灰橄榄、奶白晨光、冷蓝青、赭金、局部鲜明小色点 | 当前参考与用户指定；原图光线只在无其他要求时辅助选择 |
| 表面 | 细平交叉/点状印相；可见织物经纬；较强的旧印相颗粒 | 看参考纹理尺度与对比，不统一做成粗麻布 |
| 边缘 | 清楚的枝叶/人物/物件轮廓；柔软远景；局部运动拖影 | 由内容重要性与参考决定，不全图模糊或全图羽化 |
| 明暗 | 近黑剪影、可读中间调、柔和亮面；局部彩色光点 | 看暗部是否仍服务主题，避免压黑人物身份和产品细节 |
| 构图 | 横幅、方形、竖幅；远景留白、局部枝叶、近景船、人和地面 | 用户任务与原图优先，没有固定天空比例或地平线位置 |

典型范围：暖金群鸟图有多只鸟；冷蓝船图有红色救生圈与近景人物；田野农人图地面占主体；月与飞鸟有方图；枯枝月图为竖幅；枝叶逆光图含大量清晰细枝。这些都反驳“一个锐利锚点、全部边缘柔软、每张低地平线 3:2”的绝对规则。

“绘画般”可描述色团、气氛与哑光表面；只有用户或参考明确要求可见笔触时才加入油画笔触。别把真实摄影结构重写成古典油画，把月晕变成旋涡刷痕。

## 诗意如何落实到主题

先决定本图要传达的情绪，再选可见的关系，而不是统一加雾或复古滤镜：

- 自然：枝条疏密与水面停顿、远近层次与残留的光。细枝可以清楚，气氛不靠全部抹糊。
- 城市：人的尺度与建筑空隙、湿地与微光、街道的延伸节奏；压住竞争的灯光和高光。
- 人物：神态、姿势与窗光/阴影的关系；克制环境干扰，不把身份特征抹掉。
- 静物：物件之间的距离、光落在哪里、材质与影子的安静呼应；避免成为每处都锐利发亮的商品图。

诗意没有客观总分。目视判断画面是否有主次、含蓄的光和余韵，写出具体依据和不足；用户审美验收仍独立于作者自检。不要把新色调、新织纹或“更好看”直接写成达成诗意。

## 按主题保护内容

| 主题 | 风格适配 | 优先验收 |
| --- | --- | --- |
| 自然/湖面 | 可用灰绿、暖灰、冷蓝或烟灰；选择边幕、远景气氛或剪影之一 | 树线、岸线、倒影、主体数量；不凭空添鸟、月或船 |
| 人物/动物 | 肤色/毛色可低饱和，但面部、眼神、姿态与必要服饰可读；纹理和软化避开识别关键细节 | 人数、身份、脸/手、姿态；从零生成的泛化人像不证明真实身份保真 |
| 城市/建筑 | 从夜灯、雨色、材料本身选色；把气氛用于空气与墙面，结构不能被软化吞掉 | 建筑透视、门窗、道路、物体数量；不为风格换成水乡/森林 |
| 室内/静物/产品 | 光线可暖也可冷；细平纹理兼容材质，保住轮廓、把手、图案和文字 | 物件数量、形状、品牌/文字（若要求）、边缘可读；不为留白删物件 |
| 多主体/内容密集 | 降低纹理与对比干扰，用局部软化拉开层次；保留用户内容 | 内容完整、信息层次与用途，不强行简化成一个小主体 |

未指定构图的新图可利用克制留白，但应适合主题；编辑图保留裁切，只有明确授权重构才调整。

## 参考选取

选取最接近所需色彩与边缘处理的图，必要时再添一张表面参考。为每张写明借用部分与不借用部分。例如：冷蓝船参考只借蓝灰和运动柔化，不借船、人、红圈；暖金枝叶只借织纹与背景色，不借枝条位置。

新场景验收应核对是否意外照搬参考：主体、位置、枝形、山形或鸟群排列高度重合时，将其标为参考重绘，不能称为新构图。主体词汇是可选内容，不等于风格本身。

## 修正对应表

| 失败 | 有针对性的修正 |
| --- | --- |
| 全部变棕黄 | 再附选定参考，要求目标色温与色点关系，保留内容；不要仅说“不要黄色” |
| 月晕/天空出现旋涡油画笔触 | 回到平面摄影印相，保留自然轮廓与纹理；取消可见刷痕 |
| 树/脸/产品都糊掉 | 限定软化区域，恢复关键轮廓与识别细节 |
| 织纹只像微噪 | 按参考增强交叉纹理可见度，避免同时改色与构图 |
| 织纹粗得像麻袋 | 压平并减小纤维尺度，降低表面对比 |
| 内容/比例漂移 | 重新附原图与保留项，恢复数量、裁切和几何；不再编辑漂移版 |
| 像普通纪实/商品图，只有纹理 | 提出本图的情绪关系，压住抢眼细节和硬高光，调整层次/空间节奏；保留内容，重新看是否有余韵 |
| 色彩对了但不像参考 | 检查表面尺度、软硬关系、明暗层次，不用加鸟补救 |
| 图片像素材样本而不服务用途 | 恢复主题和使用目的，比如脸、产品形状、道路结构，而非增强纹理 |
