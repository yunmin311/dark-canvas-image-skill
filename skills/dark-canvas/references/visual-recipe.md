# 视觉配方

这些配方来自用户补发的六张清晰参考、此前六格截图与两张已认可 AI 生成案例的目视分析，不是摄影师的技术自述。清晰参考优先于拼图；既有案例是独立的 Creative OS 暖灰变体。

## 参考各自贡献什么

六格截图：烟灰阴云、小鸟/蝙蝠样飞行剪影、枝叶遮挡、灰绿横向拖影、局部旧金色与橙色漏光、暗岸线。质感柔软而暗，有些照片边缘存在胶片边缘般痕迹。

已认可风景案例：细密织纹尤其清楚，灰褐海岸、长段天空留白、微小远景锚点、近岸到远岸的雾化层次。

已认可植物案例：炭黑芦苇与细枝围住中部暖灰天空；枝叶细节可读；单个很小的暖色锚点；无明显拖影。

六张清晰参考都可见很细、较平的交叉纤维/点状表面，比旧案例的粗亚麻弱；中性灰云图的云层偏柔软，天空较亮，下缘或飞鸟近黑，极边缘偶有浅划痕/旧印相痕迹。暖灰枝叶图轮廓较硬，不能用全图模糊概括这一组。灰绿图有明显方向性拖影；旧金图只在右边出现橙色漏光。

图像的具体表面处理工艺仍不能从 JPG 确认，故本 skill 只描述可见效果。不要将旧案例更粗的织物表面误称为清晰参考的精确复刻。

## 变体选择

| 变体 | 色调与明暗 | 清晰关系 | 构图倾向 |
| --- | --- | --- | --- |
| 烟灰阴云（默认） | 中性灰近黑白，轻暖灰云口、烟灰云团、近黑下沿 | 云团柔软，孤立小主体清晰，表面细而平 | 新图保留大量天空，避免戏剧性中心光束 |
| 暖灰植物 | 羊皮纸灰、橄榄褐、炭黑枝叶 | 精细枝叶 + 软天空 | 植物从边缘进入 |
| 灰绿拖影 | 灰橄榄、煤黑、少量暖灰 | 横向/斜向局部运动痕迹 | 主体仍有至少一部分可辨 |
| 旧金漏光 | 低饱和土黄、褐黑 | 植物剪影，朦胧背景 | 仅局部边缘漏光，不默认整面橙色 |
| Creative OS 暖灰 | 比摄影参考更暖的灰褐、羊皮纸色 | 织物纤维较明显，摄影深度与细枝轮廓 | 参考已认可的两张案例 |

未指定时选烟灰阴云；主体是枝叶时可选暖灰植物。只有用户要求 Creative OS 既有案例的效果时，才优先选更暖的织物配方。不要把各种效果叠满一张图。

## 表面与色调

以观感为准，不假装工具能执行十六进制精确上色。调色提示：炭黑 #20211B，烟灰 #77766B，灰橄榄 #696A4D，旧金 #A18C4F，羊皮纸 #C8B99A。不要为了用齐色卡制造彩色物体。

默认纹理在缩略图上只形成柔和底感，放大后才清楚看见细小纤维/点状交叉；在主体和天空连续存在。Creative OS 配方可让织纹在缩略图上更可感。避免规则网格的数码感、粗糙麻布结、龟裂油画、刮刀笔触以及把背景画成材质样本。

保持暗部少量内部差异；允许剪影，但别把所有枝叶融成一坨。天空亮部不漂白，中间灰度不糊成均匀咖啡色。新图用空间深度产生柔软感；转换图只软化原图中可承受丢失细节的区域。

## 照片转换的优先级

先保结构与身份，再匹配色域/明暗，最后加表面与局部软化。照片主体与参考不同并不要求换成树林。人像保留面部辨识；室内保留家具和透视；城市保留建筑与道路。不要为“电影感”加雾、鸟、风筝、裂痕或漏光，除非用户要求或该变体需要。

## 常见偏差与定向修正

| 偏差 | 下一次只修什么 |
| --- | --- |
| 普通棕色复古滤镜 | 加强整面细织纹、冷暖灰层次与选择性剪影 |
| 油画/插画 | 强调摄影透视、自然轮廓和印相表面；去掉笔触 |
| 麻袋感太重 | 减小纤维尺度、降低表面凸起，保留色调与构图 |
| 太亮太艳 | 压缩色域、收暗中间调，保留云口亮度 |
| 一片黑 | 恢复天空层次和部分暗部细节，保持整体低调 |
| 模糊成团 | 恢复关键对象与枝叶边缘，只软远景 |
| 转换后新增/丢失对象 | 回到原图，逐项重申需要保留的对象和位置 |
