# 视觉配方

配方来自对用户提供的二十四张参考图（摄影师 Pablo Bueno，身份由用户确认）的逐张目视分析，外加两张已认可的 Creative OS 生成案例。**不是摄影师的技术自述。** 第三方参考图仅存于本地忽略目录，不随仓库分发。

## 核心原则：恒定项与可变项分离

**这个风格的"恒定项"是表面与构图语法，"可变项"是色彩。色彩由你要画的那个场景决定，不是套一层固定滤镜。**

上一版把「暖金」设为默认色域，这是把可变项当成了恒定项——参考图里并没有一张是固定色调的：冷蓝渔火、烟灰单色月、暖金夕照、灰绿雾山、橙金树冠各有各的调子。**唯一跨全部二十四张不变的是亚麻油画表面和那套构图骨架。**

| | 恒定项（每张都必须一致） | 可变项（跟场景走） |
| --- | --- | --- |
| 表面 | 亚麻织纹、哑光、晕开色团、羽化边缘 | — |
| 构图 | 3:2、低地平线、天空/水面约 2/3、层次退远、近黑剪影入画、单一锐利锚点、不对称 | 主体放哪 |
| 母题 | 鸟／飞鸟、垂柳、水面远山、小船、月或日、枯枝 | 选其中一两样 |
| **色彩** | 低饱和、明度分层、暖冷克制 | **由场景决定，见下** |

**做法**：先问"这是什么时候、什么天气、什么光线下的景"，据此选色域，再套恒定项。不要反过来先挑颜色再硬套场景。

## 历史校准结论

- **默认色域**：上一版默认「中性烟灰近黑白」，实为少数派；暖金虽最常见，但同样不是唯一调子。已废除固定默认，改为按场景选。
- **质感**：上一版要求"不是油画／去掉笔触／never an oil painting"，方向完全反了。参考是**亚麻布面油画**，用户本人称"油画的诗意感"。已废除。
- **织纹**：上一版要求"放大后才可见"，实际**缩略图级别即可见**，且是主要识别线索。
- **母题**：上一版明令"不得把案例里的小鸟自动加入"，实际鸟／飞鸟出现在至少八张，是高频核心母题。

## 表面：亚麻布面油画（恒定项，最易做错）

- **可见经纬织纹**：细亚麻经纬线在天空、水面、剪影上**连续贯通**，缩略图级别即可见。不可做成只在放大后出现的微噪。
- **哑光**：无高光反射、无清漆感、无数码照片的锐利。
- **以明度塑形**：形体靠明暗团块交代，不靠轮廓线；边缘羽化、柔和。
- **不是**：厚涂立体堆叠（impasto）、粗麻袋、规则数字网格、浮雕滤镜。

## 构图解剖（恒定项）

二十四张共有的骨架，缺一条就脱离该 family：

1. **3:2横幅**，地平线压低。
2. **天空／水面占约三分之二**，大面积留白。
3. **层次退远的山／岸**：一道比一道更淡、更低对比，形成空气透视。
4. **近黑剪影**从底部或下角进入作天然画框；暗部内部要有层次，不能压成死黑。
5. **至多一个清晰锐利的视觉锚点**（一只鸟、一轮月、一叶帆），其余全部柔和。
6. **不对称、克制**，不居中、不做英雄式构图。

## 色彩：按场景选（可变项）

下表是**从参考图归纳的场景→色域对照**，不是固定调色盘。用户指定了场景与光线时按此选；未指定时先问场景，或选最接近的一档并说明假设。

| 场景／光线 | 天空 | 中景 | 暗部 | 唯一暖色锚点 |
| --- | --- | --- | --- | --- |
| **黄昏渔火／夜渡** | 冷蓝青、石板蓝 | 蓝灰水面、低雾 | 深炭黑船与人影 | 橙红救生圈、一点灯火 |
| **烟灰单色／月夜** | 烟灰近黑白 | 浅灰分层 | 炭黑枝干 | 白色月盘 |
| **清晨薄雾湖** | 暖奶白、淡金 | 灰绿水面、雾中林 | 近黑前景芦苇 | 无（或极小一点暖光） |
| **暖金夕照／黄昏原野** | 金、赭、麦色 | 烟灰云、灰橄榄远山 | 近黑剪影 | 一点琥珀 |
| **灰绿雾山／雨后** | 灰橄榄、煤黑 | 淡橄榄分层 | 湿暗枝叶 | 极少 |
| **旧金漏光** | 低饱和土黄 | 褐黑 | 褐黑树影 | **仅一侧边缘**的橙色漏光 |

### 跨色域不变的红线

- **一律低饱和**。任何场景都不出现鲜艳色。
- **明度分层**：近黑剪影 → 中间调 → 柔和亮开口，三段分明。
- **至多一个小暖色锚点**，面积小、饱和低。船的红、灯的暖黄、救生圈的橙都属于这一档，且只有一处。
- **禁止**：橙青电影调色、HDR 浓淡、鲜蓝天空配橙霞、大面积暖褐滤镜、通幅高对比。

### 参考用色（目视取样，仅供对色参考）

炭黑剪影 `#20211B`｜烟灰云 `#77766B`｜灰橄榄远山 `#696A4D`｜暖金天空 `#C89B4A`｜旧金漏光 `#A18C4F`｜羊皮纸白 `#C8B99A`｜冷蓝水面 `#5A6B72`

调色以观感为准，不假装工具能执行十六进制精确上色；更不要为了用齐色卡而制造彩色物体。

## 母题词汇（恒定项，可选其一两样）

这些是这个摄影师反复拍的东西，属于风格的一部分：

- **鸟**：单只停枝、群飞、归鸟掠过月、雀栖竹——最高频母题
- **柳枝／枝叶自上方垂入**，形成画框
- **水面与远山**，带小船／竹筏／渔舟
- **月或日**作为小而亮的圆盘
- **枯枝逆光**
- **田野／农人／船屋**等朴素人造物，作微小尺度参照

## 照片转换的优先级

先保结构与身份，再按**原图的光线**选色域，然后加表面与局部软化。

**转换时色彩跟原图走，不要强加暖金。** 一张阴天的冷调照片转完仍应是冷调，只是表面变成亚麻油画、饱和度压低。主体与参考不同并不要求换成树林——保留原图内容，人脸保留辨识，室内保留家具透视，城市保留建筑道路。转换是重绘，不是套滤镜。

## 常见偏差与定向修正

| 偏差 | 下一次只修什么 |
| --- | --- |
| 所有图都是同一个金调 | **按场景重选色域**：夜/渔火偏冷蓝，晨雾偏奶白，夕照才用金 |
| 变成棕调复古滤镜 | 压低饱和，回到该场景本来的色相 |
| 织纹太细看不见 | **放大织纹尺度到缩略图可见**，不要改色域 |
| 织纹太粗像麻袋 | 缩小经纬线尺度、压平，去掉立体感 |
| 数码照片感／锐利 | 加强晕开色团与羽化边缘，去高光反射 |
| 主体太满、构图挤 | 扩大留白到三分之二天空，缩小主体 |
| 缺母题、像空风景 | 按母题词汇加一处鸟／柳枝／小船，别都加 |
| 一片黑 | 恢复天空层次与暗部内部细节 |
| 暖色锚点太多、像装饰 | 只留一处，缩小面积，降低饱和 |
| 转换后新增／丢失对象 | 回到原图，逐项重申要保留的对象与位置 |
