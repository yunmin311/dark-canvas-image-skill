# 成品检查与选图

查看每张实际输出文件；编辑时同时查看原图，风格时同时查看对应参考。给每项写“通过 / 有偏差 / 未达成 / 未验证”及可见依据，不用总分掩盖主体错误。

## 判定顺序

先与原图并排看颜色；再看整体笔意/背景；最后对照素材看表面。任一关键项失败不能用其他项抵消。


1. **色彩保持（关键）**：主色系、冷暖、饱和度关系、色彩面积是否相近？是否未经要求变蓝、变粉、变褐或漂白？统一色面只允许原色范围里的必要调整，不等于重新调色。
2. **整体意境（关键）**：是否平、静、色面融合、像在布面画出？是否仍在追求清晰摄影细节、强消失点、戏剧光或鲜明前后层次？用可见依据判断；细节变少、空间减弱可以是符合目标的结果，不扣质量分。
3. **布面与概括（关键）**：实际素材的经纬纤维与有底料的薄颜料是否融入主体，边缘与色形是否柔和含蓄？不能仅以纹理覆盖判定通过；粗麻、卷曲刻花、纸絮、水彩晕斑、厚涂或纯失焦需记录偏差。
4. **主题与明确条件（关键）**：主题、指定主体/数量、主要安排、画幅是否满足？微细节、局部反射/轮廓的概括不自动算结构失败；未经允许换主体、增减物件或改变裁切才应明确失败。若用户要求精确身份、字样、产品特征，逐项单独核验。
5. **笔意与诗意（关键）**：色形是否有毛笔般起收/概括，背景是否统一而平静，整体是否有余韵？不要求每个区域清楚或有强空间。不能为补“诗意”加月、加鸟、改成山水母题。
6. **成品完整性**：文件实际取得并查看、画幅与位置已确认，畸形/多余对象、字样/水印情况已记录。风格自检与用户审美认可分别写明。

关键项未达成就不能标为成品通过。无法验证的人物身份、文字或像素等价明确列为未验证。图像看起来顺眼不替代逐项检查；其他 agent 的历史 PASS 也不替代本次验收。

## 修正与停止

按影响用途最大的一个或两个偏差修正，保留已经正确的属性；每版重新看图。不改风格去掩盖内容问题，不以换场景解决局部失败。默认最多两次修正，用户预算优先。

有一版关键项通过则从通过版本中选最合适的；最后一版退步时保留之前更好的版本。若达到上限仍失败，保存最佳结果，状态为部分达成/未达成，写清未达标项和下一步所需条件。工具不可用或文件未取得，则是未执行/未完成，不是“应该可以”。

## 每张交付记录

- 请求与用途；主题；输入角色和为什么选这组参考。
- 必须保留、可以改变、画幅与关键验收项。
- 实际工具与完整提示词；每版图片路径与查看记录。
- 逐项观察；需要修正的具体偏差、每轮改了什么。
- 最终选图路径、选择依据、通过/部分达成/未达成/未验证状态与残留问题。

文字记录不能代替最终图片。交付最终文件及必要的原图对照，让用户直接查看；准确说清哪些要求已满足、哪些仍未证明。公开参考须有发布依据，用户照片默认本地保存。
