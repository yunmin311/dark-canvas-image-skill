# 按选定表达检查最终图片

实际查看源图、对应作品与每张输出。每项写通过/有偏差/未达成/未验证及可见依据，不能用总分抵消关键错误。文件校验和工具调用不等于视觉通过。

1. **原图颜色与内容（关键）**：主色、冷暖、颜色面积、主题、指定数量、主要安排和裁切仍相近吗？未经要求的偏褐/变蓝/漂白、换景或新增物件均需修正。用户要求精确身份、文字或产品细节时单独核验。
2. **选定表达（关键）**：保留摄影、毛笔、剪影或雾化是否符合参考？剪影应允许利落轮廓；毛笔看起收/方向/简洁色形；摄影看自然不规则和主题可辨；雾化看有无分区/方向及识别形状。不能所有主题都按“轮廓越软越好”验收，也不能把笔形简化成全图油画塑形。
3. **材质与旧痕（关键）**：需要布面时经纬是否融入图像，密度/尺度/强度接近参考？选了做旧时保留有层次的不均匀旧痕、擦痕、露底和颜料缺口，不能去噪抹干净；没选做旧时不能加脏斑。生成示意素材不等于旧画布实拍，不能凭素材名称判通过。卷曲装饰纹、墙皮/石膏或过大的破洞要记录偏差。
4. **晕影与统一诗意（关键）**：边缘处理是否为选定的无/轻/明显，过渡是否宽缓？是否错把阴云/漏光/拖影当成晕影？整体安静、连续色面、克制微反差且保留该张独特表达吗？不要靠强黑框、艳色滤镜、整图磨糊或合成道具解释诗意。
5. **交付完整性**：文件实际取得并查看，尺寸/画幅有依据，明显畸形、新增字样/角落标识已记录。风格自检与用户视觉认可分别说明。写了提示词而未出图，应报告未执行图生图效果验证。

关键项失败时修正最影响用途的一至两项，保留正确属性。默认初稿加最多两次修正，逐版看图；从符合要求的最佳版选图，不自动选最后一张。连续无改善、次数到顶或工具失败后保存最佳结果及残余偏差，标为部分达成/未达成。

每张记录源图/参考/素材角色、选择理由、必须保留和可以改变的内容、实际工具与完整提示词、版本文件、每轮可见观察、最终选择及状态。优先用户真实照片，不再用已否定的合成跨主题场景做验收。主题相似不证明身份、文字或像素保真。
