# 按选定表达检查最终图片

实际查看源图、对应作品与每张输出。每项写通过/有偏差/未达成/未验证及可见依据，不能用总分抵消关键错误。文件校验和工具调用不等于视觉通过。

风光、乡间与近物先按 [默认画布与光色](canvas-and-light.md) 核验，再看 [各组适配](landscape-adaptation.md)。田野农人排除，灰湖颗粒低优先级；共同经纬布面保持默认。枝叶不要求一律模糊，远山水面不要求删除全部结构，人物分静态与活动；复杂城市背景不作为现有自然作品组的主验收样本。对应作品缺失、没有实际出图的组保持未验证状态。

1. **原曝光、光色与主体（关键）**：先对照原天空、暗树/地面、水面和主体的亮暗。是否抬曝光、提暗部、新增光源/轮廓光或照亮原本无亮细节的叶片？饱和度与明度分开判断；材质接近不能抵消曝光错误。再看主体、识别轮廓、主要关系、用户指定数量及裁切是否保留？授权删减的次要元素不用逐一保真。拥挤输入是否真的减少了无关物件、文字和零碎亮点，使主体与背景成为有主次的平面色形？主色与冷暖是否仍来自原图，允许小色点合并或消失。未经要求的整图偏褐/变蓝/漂白、主体消失或新增物件需修正。用户要求精确身份、文字或产品细节时单独核验。
2. **选定表达（关键）**：自然薄色形、笔意、剪影或柔化是否符合本次实际作品？近枝可保细线，山水可为柔色带，云场保大走势，运动保局部方向与支点；剪影允许利落轮廓，笔意看起收/方向。不能所有主题都按“轮廓越软越好”验收，也不能把笔形简化成全图油画塑形。
3. **材质与旧痕（关键）**：实际对照选定作品，看经纬可见尺度、强度、旧斑分布和主体/底布关系；不能仅因“有布纹”就判通过。目标中人物/剪影是薄色形时，输出不能保持高清塑形主体，再单独给背景叠材质。选了做旧时保留不均匀旧痕、擦痕、露底和颜料缺口，没选时不能加脏斑；碎亮笔触、水彩渗边、凸起厚涂和规整海报块均须记录。生成示意素材不等于旧画布实拍，不能凭素材名称判通过。
4. **晕影与统一诗意（关键）**：边缘处理是否为选定的无/轻/明显，过渡是否宽缓？是否错把阴云/漏光/拖影当成晕影？整体安静、连续色面、克制微反差且保留该张独特表达吗？拥挤照片只叠布纹、滤镜或磨糊而未完成色形取舍，判为未达成；不要靠强黑框、艳色滤镜或合成道具解释诗意。
5. **交付完整性**：文件实际取得并查看，尺寸/画幅有依据，明显畸形、新增字样/角落标识已记录。风格自检与用户视觉认可分别说明。写了提示词而未出图，应报告未执行图生图效果验证。

关键项失败时修正最影响用途的一至两项，保留正确属性。默认初稿加最多两次修正，逐版看图；从符合要求的最佳版选图，不自动选最后一张。连续无改善、次数到顶或工具失败后保存最佳结果及残余偏差，标为部分达成/未达成。

有人物时另外看：姿态与色形是否成立，内部是否仍有过多衣褶、标识和装备细节？选了拖影/叠影时是否局部、含蓄且没有新增肢体或人数，布面是否保持？静态人物不强制运动效果。用户认可材质后，不能继续把正常与破旧画布都列为失败，也不能通过换掉材质回避主体问题。

每张记录源图/参考/素材角色、选择理由、必须保留和可以改变的内容、实际工具与完整提示词、版本文件、每轮可见观察、最终选择及状态。优先用户真实照片，不再用已否定的合成跨主题场景做验收。主题相似不证明身份、文字或像素保真。
