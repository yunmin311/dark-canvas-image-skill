# 当前作品观察与优先级

24 张附件已逐张观察。田野农人按用户要求排除，23 张参与目标观察；其中灰湖颗粒降为低优先级例外。两对近似构图保留核对，不增加独立风格论据。默认共同经纬画布优先，七组只用于主体及局部处理，不是七种材质平行选择。

先保持源照片曝光、光向和主色，再选择正确原作共同画布。枯枝月为已认可的布面基准，柳丝/竹叶校准较干净的版本；旧痕变化不等于换材质。见 [画布与光色](canvas-and-light.md)。

逐张的十二项观察见 [完整研究](reference-study.md)，数据见 [JSON](reference-map.json)，迁移建议见 [主题适配](landscape-adaptation.md)。可见拖曳、叠合、亮带只描述外观，实际拍摄和后期方法未确认。

## 实测状态

此前柳岸、公园的两组四张候选已被用户全部否定。曝光、锐化/碎笔和材质偏离都是关键错误；不得标为部分认可或用作正确参考。新的原曝光/画布优先尝试另存本地，未获得用户认可前只算候选。
